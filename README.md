# 🤖 AI CHATBOT
!!
AI CHATBOT is a minimal chatbot web application built using **Python (FastAPI)** for the backend and **HTML, CSS, and JavaScript** for the frontend.


## 🎯 Project Purpose
- Practice Python backend development with FastAPI
- Understand frontend and backend communication
- Learn AI integration step by step
- Maintain consistent daily GitHub activity

---

## ✨ Current Features
- Single-page chat interface
- FastAPI backend with `/chat` endpoint
- Frontend connected to backend API
- Mock AI response (initial version)
- Environment variable handling added

---

## 🛠️ Tech Stack
- Backend: Python, FastAPI
- Frontend: HTML, CSS, JavaScript
- API: REST
